# 2026-08-18 — SignalTap desktop MVP (Phase A) built

## What was built
Full desktop MVP per the product spec, in a fresh npm-workspaces monorepo at the repo root:

- `packages/schemas` — Zod contract: ExtractedContent, AnalysisRequest, AnalysisResult, WorthAttentionScore, Feedback, ApiError (SCHEMA_VERSION "1.0").
- `packages/analysis` — 8-dimension worth-attention scorer (transparent profile weights, never LLM-invented), staged comment clustering (clean→dedupe→union-find→stats, deterministic mock), provider interface + retry/timeout/abort, MockAnalysisProvider, OpenAI-compatible provider (`llm.ts`) used only when OPENAI_API_KEY is set.
- `apps/backend` — Hono API (Node now, Cloudflare-compatible): POST /v1/analysis, GET/DELETE /v1/analysis/:id, POST /v1/feedback, /health. Size limits, sanitize/truncate, in-memory rate limit, metadata-only logs. Runs with `tsx` (no dist build needed).
- `apps/extension` — Chrome MV3, minimal permissions (activeTab, sidePanel, storage, scripting; NO host_permissions). Background SW opens panel + injects content.js via chrome.scripting. Content script: adapter system (GenericArticle/Reddit/HackerNews/GitHubIssue/YouTube/GenericVisibleText), click-to-highlight with "SignalTap source" label, FAB, in-page fallback panel. React+Tailwind side panel: real staged loading, verdict, facts/opinions/consensus/disagreement, click-to-source, history, settings (profile/history/content-retention), report/delete, cancel/retry. Local cache via content fingerprint (fnv1a) + chrome.storage.local.
- Tests: 38 Vitest unit tests (extension) + 9 backend API tests, all passing. Playwright e2e (2 specs) with local fixtures + backend webServer.

## Key decisions / deviations from spec
- pnpm not installed (global installs disallowed) → npm workspaces, documented in README.
- Extension built via 3 Vite configs so content.js/background.js are self-contained IIFEs (injectable as classic scripts); side panel is the app build. Build = `vite build && vite build -c vite.config.content.ts && vite build -c vite.config.background.ts`.
- Default provider is the deterministic mock (free, no key). Real LLM only when OPENAI_API_KEY set; falls back to mock on invalid_output/provider_unavailable.
- Score normalization: weights are absolute; signs come from DIMENSION_DIRECTIONS (novelty/relevance/evidenceQuality/infoDensity/actionability positive; redundancy/uncertainty/promotionalIntensity negative).

## Environment gotchas (Windows)
- `npm install` cleanup warnings + corrupted extracted `http-proxy-agent` (missing dist/index.js) — fixed by downloading the tarball from registry.npmjs.org directly and extracting into node_modules. If jsdom tests fail with "Cannot find module 'http-proxy-agent/dist/index.js'", redo that.
- `CSS.escape` not in TS DOM lib → ambient declaration added in `adapters/dom.ts`.
- `getComputedStyle` global missing in node vitest env → `isVisible` now uses `el.ownerDocument.defaultView?.getComputedStyle`.

## E2E + Windows safe-delete shim follow-up
- Playwright Chromium installed to `D:/CODE/project/SignalTap/.cache/ms-playwright` (project-local; default `C:/Users/.../ms-playwright` blocked by the trash shim). Set `PLAYWRIGHT_BROWSERS_PATH` to the project path when running e2e.
- The Windows "genie-safe-delete" shim wraps Node `fs.rm` and THROWS *after* removal succeeds. That breaks Vite emptyOutDir, Playwright's test-results cleanup, and Playwright's `__dirlock` removal. Workarounds:
  - `apps/extension/scripts/prebuild-clean.mjs` (run before every `build` / `test:e2e`): `rmSync` dist + test-results + playwright-report, swallow the shim's error (the dirs are gone anyway).
  - Playwright config uses `headless: false` — Chromium ignores `--load-extension` in headless mode.
  - e2e helper polls `context.serviceWorkers()` for up to 25s (MV3 SWs start lazily, the 'serviceworker' event does not fire for dormant workers).
- **Important gotcha during e2e debugging**: a failed `npx` spawn in a debug script killed the test process *before* `vite build` ran, but *after* `prebuild-clean` had already deleted `dist/`. Result: `dist/` empty → Chrome "Manifest file is missing or unreadable" error. Always rerun `npm run build` before loading the extension in the browser. `prebuild-clean` is wired into `build`, `build:sidepanel`, and `test:e2e` scripts, so the normal flow stays safe.
